# MSOC UK Carol Virunnu 2026 Guidelines

A responsive single-page website containing the official competition rules, performance guidelines and judging framework.

## Publish on Render

1. Upload this folder to a GitHub repository.
2. In Render, choose **New → Static Site** and connect the repository.
3. Leave the build command empty.
4. Set the publish directory to `.`.
5. Deploy.

The included `render.yaml` also supports Render Blueprint deployment.
